# لوحة تحكم مدار تك — صفحات مستقلة

افتح `dashboard/dashboard.html` عبر Live Server لصفحة النظرة العامة.

- `programs.html`: مجموعات البرامج والبرامج ومسوداتها.
- `content.html`: الواجهة الرئيسية والأقسام والبطاقات وترتيبها وظهورها.
- `identity.html`: ألوان الهوية والاسم ووصف المؤسسة.
- `contact.html`: البريد وواتساب وإنستغرام والعنوان.
- `backup.html`: تصدير واستيراد الإعدادات واستعادة الافتراضي.

تستخدم الصفحات الست ملفي dashboard.css وdashboard.js وملف ../site-data.js المشترك مع الموقع. لا توجد أقسام صفحات أخرى مخفية داخل صفحة واحدة. روابط التنقل تنقل إلى ملفات HTML مستقلة.

الحفظ تلقائي محليًا عبر madar.site.v2 بعد 450 مللي ثانية من آخر تعديل، وقبل التنقل. تستورد بيانات البرامج القديمة عند عدم وجود v2. تتحدث نافذة الموقع على الأصل نفسه، ولا تُرسل تغييرات المحتوى إلى GitHub أو الزوار الآخرين. صدّر نسخة قبل مسح بيانات المتصفح. اللوحة ليست محمية بتسجيل دخول.

المرجع البصري: https://madartech-animationspage.vercel.app/ . استُلهم تخطيط البنتو وبطاقات الدخول والارتفاع الخفيف عند التحويم، مع ألوان مدار تك ومراعاة تفضيل تقليل الحركة. الأرقام من المحتوى المحفوظ فقط.
