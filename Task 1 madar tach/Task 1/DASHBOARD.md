# لوحة تحكم مدار تك

افتح المجلد عبر Live Server في VS Code ثم افتح index.html واختر «لوحة التحكم»، أو افتح dashboard.html مباشرة عبر الخادم نفسه.

يمكن إضافة البرامج وتعديلها وحذفها والبحث فيها وحفظها كمسودة أو إظهارها في الموقع. الأرقام محسوبة من البرامج الفعلية، دون بيانات إحصائية وهمية.

هذه نسخة محلية تستخدم localStorage: التغييرات تخص المتصفح وأصل الموقع نفسه، ولا تعدّل ملفات GitHub ولا تظهر للأجهزة الأخرى. مسح بيانات الموقع يمسح التعديلات المحلية. لا يوجد تسجيل دخول أو خادم أو قاعدة بيانات. يلزم ربط خلفية وصلاحيات إدارة قبل استخدامها كنظام إدارة مشترك. لا تُدخل بيانات حساسة.

ملفات الموقع الأصلية محفوظة باستثناء إضافة رابط لوحة التحكم وملف تحميل البرامج في index.html. نموذج واتساب الأصلي يحتاج رقمًا صحيحًا بدل الرقم التجريبي.
